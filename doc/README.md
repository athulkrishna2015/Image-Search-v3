# Image Search v3 — Documentation

This folder holds the contributor and maintainer reference for the
**Image Search v3** Anki add-on.

| File | Purpose |
| --- | --- |
| [ARCHITECTURE.md](ARCHITECTURE.md) | High-level component diagram, data flow, lifecycle. |
| [MODULES.md](MODULES.md) | Per-module reference: every public function, what it does, who calls it. |
| [CONFIG.md](CONFIG.md) | Every JSON key (per-note-type and global) with type, default, and meaning. |
| [STATE.md](STATE.md) | Module-level mutable state, caches, and how they are scoped. |
| [PROVIDERS.md](PROVIDERS.md) | Each image search provider: URL, parameters, parser notes, fallback policy. |
| [ERRORS.md](ERRORS.md) | Error codes, error messages, and what they mean for the user. |
| [BUILD.md](BUILD.md) | Build script, version bump rules, packaging, local dev symlink, code standards. |
| [SECURITY.md](SECURITY.md) | Key rotation, git hygiene, network safety. |
| [TESTING.md](TESTING.md) | How to run the test suite, what's covered, what to add. |

End-user documentation is in [README.md](../README.md). The full
release history is in [CHANGELOG.md](../CHANGELOG.md).
