# Configuration Reference

Image Search v3 stores configuration in two places:

1. **`addon/config.json`** — defaults shipped with the add-on. Read by
   Anki the first time the add-on is installed, or when a key is
   missing from `meta.json`. Safe to commit.
2. **`addon/meta.json`** — Anki-managed runtime config (per-user
   overrides). **Gitignored.** This file may contain credentials and
   is regenerated by Anki.

Both files share the same JSON shape. The keys below describe that
shape.

## Top-level keys

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `provider` | string | `"yandex"` | One of `"yandex"`, `"duckduckgo"` (alias `"ddg"`), `"google"`. |
| `google_api_key` | string | `""` | Google Custom Search JSON API key. Only used when `provider == "google"`. |
| `google_cx` | string | `""` | Google Custom Search Engine ID (`cx`). Only used when `provider == "google"`. |
| `google_fallback_to_yandex` | bool | `true` | When the Google provider returns no results (or no key is configured), fall back to Yandex. |
| `request_timeout_s` | float | `10.0` | Per-request timeout in seconds. Clamped to `[1.0, 120.0]`. |
| `max_retries` | int | `5` | Number of retries after the first attempt (i.e. up to `max_retries+1` total requests). Clamped to `[0, 10]`. |
| `backoff_base_s` | float | `0.75` | Exponential backoff base in seconds. Sleep before retry `n` is `backoff_base_s * 2 ** n`. Clamped to `[0.05, 10.0]`. |
| `log_level` | string | `"info"` | One of `"debug"`, `"info"`, `"warning"`, `"error"`, `"critical"`. Controlled from the Logs tab. Unknown values are ignored. |
| `configs_by_notetype_id` | object | `{}` | Map of note-type id (as string) → per-note-type config (see below). |

### Legacy keys (ignored at runtime, cleaned on save)

| Key | Reason |
| --- | --- |
| `query_field` | Replaced by per-note-type `query_fields`. |
| `query_fields` (at top level) | Replaced by per-note-type `query_fields`. |
| `image_field` (at top level) | Replaced by per-note-type `image_field`. |
| `search_engine` | Replaced by `provider`. |

These are stripped on the next `Save` click in the settings dialog.

## Per-note-type keys (under `configs_by_notetype_id["<nt_id>"]`)

| Key | Type | Meaning |
| --- | --- | --- |
| `query_fields` | string[] | Field names whose content is used as the search query when the user does not have a selection. Case-insensitive. Supports "Front" → "Text" remap for Cloze note types. |
| `image_field` | string | Field name where the resulting image will be inserted. If the field does not exist on the note type, the user is warned and the last field is used. |
| `image_placement` | string | One of `"replace"` (smart replace only touches prior `<img class="imgsearch">` tags, falls back to append), `"append"`, `"prepend"`. |

## `addon/manifest.json` (Anki-side, not user-editable)

| Key | Type | Meaning |
| --- | --- | --- |
| `package` | string | Anki add-on id (`178037783`). |
| `name` | string | Display name. |
| `author` | string | Author name. |
| `version` | string | `3.<major>.<minor>`. The leading `3` is fixed. |
| `homepage` | string | AnkiWeb URL. |
| `mod` | int | Unix timestamp of last manifest update. |
| `min_point_version` | int | Lowest supported Anki point version (`25` for Anki 25.x). |
| `max_point_version` | int | Highest supported Anki point version. |
| `branch_index` | int | AnkiWeb branch. |
| `disabled` | bool | If true, the add-on is installed but disabled. |
| `config` | object | Optional defaults applied to `meta.json` on first install. |

## Storage summary

```
addon/
├── config.json   ← defaults (committed, never contains secrets)
├── meta.json     ← user state, possibly with secrets (gitignored)
├── manifest.json ← add-on descriptor (committed)
└── VERSION       ← plain-text version, written by bump.py (committed)
```
